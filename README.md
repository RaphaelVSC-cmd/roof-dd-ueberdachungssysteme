# Roof D&D Überdachungssysteme GmbH – Premium Website

> Maßgefertigte Terrassenüberdachungen, bioklimatische Lamellendächer, Wintergärten & Markisen in Augsburg und Schwaben.

---

## 🌟 Features & Highlights

- **Modern UI Pro v3.2 & Awwwards-Design:** Ethereal Glass & Architectural Precision, Double-Bezel Kacheln, Aurora-Gradienten.
- **Palomar Header-Pattern:** Einklappbare Announcement-Info oben, Glass-Navbar bei Scroll, Dark/Light Mode Toggle.
- **Sticky Card-Stacking (§ 15):** 4 gestapelte Produktkarten mit sanftem Skalierungseffekt beim Scrollen (Mobile-Fallback für Smartphones).
- **Scroll-Driven Dual Marquee (§ 16):** Zwei gegenläufig scrollende Tracks für Detailaufnahmen und Qualitätsmerkmale.
- **Interaktiver System- & Maß-Rechner (§ 6):** Sofortige Preisschätzung für Terrassendächer, Lamellendächer und Wintergärten.
- **3-Step Funnel Kontaktformular (§ 5):** Spielerische Bedarfsanalyse, Validierung, Spamschutz & DSGVO-Checkbox.
- **Rechtssicheres Modal-System (§ 9):** Impressum (§ 5 TMG) & Datenschutzerklärung (DSGVO Art. 13) als responsive Dialog-Cards.
- **DSGVO Consent Banner (§ 2):** Blockiert Google Maps bis zur Nutzereinwilligung.
- **WhatsApp Widget (§ 4):** Direkter Chat via `wa.me/498214544735`.
- **Accessibility (WCAG 2.1 AA):** Skip-to-Content, ARIA-Labels, Keyboard-fähiges FAQ-Akkordeon.

## 🚀 Lokale Vorschau starten

Einfach einen lokalen HTTP-Server im Projektordner starten:

### Windows:
Doppelklick auf `start.bat` oder im Terminal:
```cmd
python -m http.server 8000
```
Öffne anschließend [http://localhost:8000](http://localhost:8000).

### macOS / Linux:
```bash
bash start.sh
```
